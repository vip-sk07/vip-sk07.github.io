## ✨ Features

- ** Futuristic Dark-Theme UI:** Cyberpunk aesthetics with CSS glassmorphism, animated background starfield canvas, glowing orbs, and micro-interactions.
- **🤖 Interactive Portfolio AI Assistant:** Built-in client-side simulated AI chat bot indexed with Karan's verified skills, projects, CGPA, and academic record.
- **📍 Active Navbar Scrollspy:** Dynamic navigation tracking that highlights the active section link as you scroll through the page.
- **⚡ Performance & Visibility Optimized:** Canvas animations automatically pause when the tab is hidden (`document.hidden`) or scrolled out of view (`IntersectionObserver`).
- **♿ Accessibility & Mobile-First:** Includes `@media (pointer: coarse)` mobile touch support and `@media (prefers-reduced-motion: reduce)` accessibility compliance.
- **🌐 OpenGraph & SEO Ready:** Rich metadata tags for preview cards on LinkedIn, Twitter, and messaging platforms.

## 🚀 Quick Start (Local Development)

Since this is a lightweight vanilla web application, no npm build steps are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vip-sk07/vip-sk07.github.io.git
   cd vip-sk07.github.io
   ```

2. **Serve locally:**
   Using Python's built-in HTTP server:
   ```bash
   python3 -m http.server 8000
   ```
   Open `http://localhost:8000` in your web browser.
